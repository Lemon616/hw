# Pix2Pix with Fully Convolutional Layers

## Introduction

This project implements the Pix2Pix image-to-image translation framework using Fully Convolutional Networks (FCNs).  In this implementation, we enhance the original Pix2Pix model by adding fully convolutional layers to improve spatial consistency and translation quality.

## Requirements

To run this project, the following libraries are required:
Python 3.10
pytorch
anaconda
These packages support image manipulation, mathematical operations, and visualizing results.

## Complete the code

 Define a convolutional neural network, starting with the encoder, which includes multiple convolutional layers, batch normalization layers, and activation functions. Define the decoder section, using transposed convolutional layers to gradually restore the feature maps to the original input size.

## Training Steps

1.Configure the appropriate environment to run download_facades_dataset.sh, generating the image set; also generate train_list.txt and val_list.txt. This part requires patience to set up the environment for generating the dataset, as there may be instances where train_list.txt and val_list.txt are empty, but successful debugging was achieved.
2.Run the train.py file provided by the instructor. Training begins, running for 800 iterations, with 4 steps completed in each iteration, and the loss function calculated for each step.

## Results
This experiment primarily used the dataset provided by the instructor for training, implementing pix2pix using a convolutional neural network method. The training results were quite satisfactory, but the training efficiency needs improvement.
The final output consists of two result folders, each containing 795 subfolders that clearly document the training and optimization processes. To save upload space, only the first two and the last four training results were retained.
