# Poisson Image Editing 

## ntroduction

This project implements Poisson Image Editing in Python, where we blend a source image into a target image seamlessly by specifying a mask region. The process involves defining a custom polygon-to-mask function and computing the Laplacian distance to achieve smooth blending based on gradients.

## Requirements

To run this project, the following libraries are required:
Python 3.10
NumPy,gridio,pytorch

It's the first time to use pytorch,need some time to configure and debug the environment.These packages support image manipulation, mathematical operations, and visualizing results.
